# ISUFST San Enrique Campus — Organizational Chart

A simple responsive website for presenting the **organizational structure of ISUFST San Enrique Campus**, with a dedicated activities page for the **College of Informatics and Computer Innovations (CICI)**.

## Project Overview

This project provides a simple and accessible way to view:

* ISUFST San Enrique Campus organizational structure
* University administration and college leadership
* CICI faculty and personnel
* CICI activities and events
* Activity photo galleries

The website includes two main navigation pages:

* **Home** — Campus Organizational Chart
* **Activity** — CICI activities and events

## Features

* Responsive design for desktop and mobile
* Glass-style interface with a blue campus theme
* ISUFST San Enrique Campus organizational chart
* CICI activity cards
* Activity photo galleries
* Mobile navigation menu
* Image gallery navigation with previous/next controls
* Keyboard support for gallery navigation
* Back-to-top functionality
* Font Awesome icons
